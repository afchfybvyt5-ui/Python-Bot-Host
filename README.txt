📘 تعليمات التشغيل:

1. افتح ملف bot.py وعدّل السطر:
   BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
   وضع مكانه التوكن الجديد من @BotFather

2. غيّر API_ID و API_HASH بالقيم من موقع my.telegram.org

3. لتشغيله محليًا:
   pip install -r requirements.txt
   python3 bot.py

4. لتشغيله على Render:
   - ارفع الملفات الثلاثة إلى GitHub
   - في Render اختر "Web Service"
   - في أمر التشغيل اكتب:
     python3 bot.py
